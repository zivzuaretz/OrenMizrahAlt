# אורן מזרח מוכרת 250M אלטשולר שחם💸

לוח מכירות סטטי, עצמאי ורספונסיבי בעברית (RTL), ללא ספריות או תלויות חיצוניות.

## הפעלה מקומית

```bash
npm run serve
```

ואז לפתוח `http://localhost:8080`. אפשר להשתמש גם בכל שרת סטטי אחר. פתיחה ישירה של `index.html` עלולה לחסום את טעינת `data.json` בגלל מגבלות הדפדפן.

## עדכון נתונים בצ׳אט

כל הנתונים הניתנים לעריכה מרוכזים ב־`data.json`. סכומי הקבוצות, הסכום הכולל, היתרה והאחוז מחושבים אוטומטית **רק** מרשימת הסוכנים.

דוגמה לסוכן (להוסיף למערך `agents` של הקבוצה המתאימה):

```json
{
  "id": "unique-agent-id",
  "name": "שם הסוכן",
  "sales": 1250000
}
```

- `sales` הוא סכום בשקלים כמספר, ללא פסיקים או סימן מטבע.
- אין להזין סכום כולל לקבוצה; הוא נגזר אוטומטית.
- `lastUpdated` הוא חותמת זמן בתקן ISO 8601, לדוגמה `2026-07-27T17:07:00Z`.
- יעד הקמפיין נמצא ב־`campaign.target` ותאריך היעד ב־`campaign.deadline`.

## בדיקות

```bash
npm test
```

הבדיקה מאמתת את מבנה הנתונים, שמות הקבוצות, יעד הקמפיין, ריקנות רשימות הסוכנים בתחילת הדרך וקיום קובצי האתר והנכסים.
